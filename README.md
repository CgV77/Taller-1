## 📂 Estructura del Repositorio
El repositorio está organizado de la siguiente manera :

* **`index.html`**: Archivo principal que contiene toda la estructura de la página web.
* **`README.md`**: Documentación técnica del proyecto (este archivo).
* **`multimedia/`**: Carpeta contenedora de los recursos multimedia del sitio.
  * `imagen2.jpg`: Imagen ramdom.
  * `imagen1.jpg`: imagen ramdom
  * `audio.mp3`: Archivo de audio.
  * `video.mp4`: Recurso audiovisual.

## Entorno de Desarrollo y Control de Versiones
Debido a limitaciones técnicas de arquitectura del sistema operativo (32 bits), el proyecto se gestionó y desarrolló de manera eficiente en la nube utilizando el entorno virtual **Visual Studio Code en la Web (github.dev)**. 

Se realizaron los **5 commits significativos** requeridos para evidenciar el avance incremental y el dominio de herramientas de control de versiones con Git.
